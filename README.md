# Legal Firm Management System — Graduation Project (2025)

A comprehensive management system designed for law firms to streamline case handling, client communication, HR workflows, financial operations, and internal administration.  
This project was developed as the graduation project for the Software Engineering degree at **Damascus University (2025)**.

---

## 🚀 Overview

The system provides a unified platform connecting lawyers, clients, HR staff, accountants, and administrators.  
It includes:

- Mobile App (Flutter)
- Web App (Flutter Web)
- RESTful API (Laravel)
- MySQL Database
- Role-Based Access Control (RBAC)
- Case & Session Management
- HR & Payroll System
- Legal Document Management
- Points-Based Hybrid Model for lawyer fee distribution

`Legal_Firm_Management_System_Thesis.pdf`

## 🧩 Key Features

### 🔹 Case & Session Management
- Add, manage, and track cases  
- Assign sessions to lawyers  
- Record attendance & results  
- Lawyer performance scoring with a points system  

### 🔹 Client Portal
- Track case progress  
- Upload legal documents  
- Request legal consultations  
- Browse legal library & news  

### 🔹 HR Module
- Job postings  
- Manage employees & applications  
- Schedule interviews  
- Leave requests & approvals  

### 🔹 Accounting Module
- Invoice creation & tracking  
- Salary management  
- Automated fee distribution  

### 🔹 Admin Dashboard
- Full control of user roles  
- Permissions management (RBAC)  
- Performance reports  
- Complaint management
